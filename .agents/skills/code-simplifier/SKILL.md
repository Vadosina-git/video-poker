Сначала прочитай проектные AGENTS.md/CLAUDE.md, `../GODOT_CONVENTIONS.md`, `docs/CODEX.md` и `docs/CODEX_PLUGIN_PARITY.md`. Сопоставление среды - `~/.codex/migration/bridge.md`. Снимки исходных процедур ниже сохранены полностью; поправки этого Codex-входа и правила проекта имеют приоритет.

Прочитай `references/code-simplifier.md`. Сохраняй функциональность, начисления/выплаты, сигналы, save-формат, публичные контракты и архитектуру. По умолчанию область - измененный в текущей задаче код; имя роли не разрешает массовую перепись проекта.

Универсальные примеры ES modules/React/function из исходника не являются правилами GDScript. Фактические GODOT_CONVENTIONS и CODE_STYLE важнее: статическая типизация, имена, порядок членов, программные стили UI и сцены через load(). Не переносить баланс из JSON в код, не менять ConfigManager/Translations, не добавлять зависимости. `model: opus` не является требованием другой модели.

Проверяй затронутое поведение по проектным TESTING_GUT и инструкциям Codex. tests/run_all.sh сам по себе не доказывает успех: проверяй реальные коды процессов, parse/runtime errors, число assertions и skips. Небольшое упрощение допустимо внутри уже порученной реализации, отдельная массовая переработка требует соответствующей задачи. Объясняй владельцу существенное изменение и проверку простыми словами.
