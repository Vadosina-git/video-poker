# Соответствие плагинов Video Poker: Claude → Codex

Повторная проверка 01.11.2026. Источник — `.claude/settings.json`:
15 записей, **7 включены и 8 явно выключены**. Значение `false` не означает
подключённый плагин. Claude settings сохранены, архитектура Godot не менялась.

## Включённые процедуры и инструменты

| Плагин Claude | Рабочий эквивалент в Codex | Граница проверки |
|---|---|---|
| feature-dev | Местный `$feature-dev`: изучение → архитектура → реализация → независимая проверка | Native SKILL и сохранённые ресурсы ролей; чужие модели/tools заменены фактическими средствами Codex |
| code-review | Местный `$code-review`: проверка изменений/PR, доказательства, отсев ложных замечаний | Сам отчёт не отправляет GitHub comment; отправка требует поручения |
| code-simplifier | Местный `$code-simplifier`: упростить затронутый код с сохранением поведения | Соблюдает статическую типизацию, конфиги и границы игрового ядра |
| claude-md-management | Глобальные `$claude-md-improver`, `$revise-claude-md` с `~/.codex/migration/bridge.md` | Знания для Codex сохранять в AGENTS и профильных docs; исходники Claude ради совместимости не переписывать |
| commit-commands | Глобальные `$commit`, `$commit-push-pr`, `$clean-gone` | Текущий запрос определяет авторизацию; migration не разрешает удалять ветки или отправлять изменения сам по себе |
| context7 | Реально подключённый MCP Context7, если доступен; иначе официальная документация через доступный web/browser | Markdown не устанавливает MCP и не подтверждает соединение. Подмена авторизации запрещена |
| serena | Реально подключённый MCP Serena, если доступен; иначе rg, чтение и точечные файловые правки | Файловые операции доступны без Serena; семантические возможности сервера без подключения не обещать |

Местные навыки лежат в `.agents/skills/`; их читать вместе с AGENTS.md,
CLAUDE.md и `../GODOT_CONVENTIONS.md`. Процедурные этапы сохраняются, но
вызовы Claude, старые allowlists и model names не исполняются. Отсутствие
collaboration tools означает последовательное выполнение и явное указание,
что независимой проверки другим агентом не было.

## Явно выключенные плагины

Следующие записи имеют `false`: `agent-sdk-dev`, `chrome-devtools-mcp`,
`firecrawl`, `flutter`, `frontend-design`, `pyright-lsp`, `supabase`,
`typescript-lsp`. Их не включали и не делали автоматически активными при миграции.
Flutter-процедуры не относятся к этому Godot-агрегатору. Agent SDK приложения,
Supabase и LSP не становятся частью игры из-за прежней записи настройки.
При отдельной задаче нужны соответствующие доступные инструменты и инструкции.

## Что подтверждено

Проверены фактические bool настроек, существующие процедуры включённых
плагинов и их входы Codex. Это проверка переноса рабочего порядка, не
запуск Godot, внешнего MCP или реального PR-review с публикацией.
Текущее подключение к серверам/auth и действительные инструменты сверять
в каждой сессии. Внутреннее рассуждение другой модели и runtime Claude
одними файлами инструкций не воспроизводятся.
