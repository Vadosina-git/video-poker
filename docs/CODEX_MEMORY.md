# Перенесённая память проекта

Прочитаны только Markdown-файлы memory этого проекта, не чаты/JSONL и не чужие vault.
Оригиналы сохранены приватно в `~/.codex/migration/project-memory/Godot-video-poker/` (каталог 700, файлы 600); SHA-256 и provenance — `.codex/project-migration.json` → memories.
Даты, тестовые счётчики, версии SDK и статусы сторов из памяти являются историей,
не новым подтверждением. Свежий код, профильные docs и поручение владельца уточняют их.

- Не git add/commit/push до явного поручения владельца. Источник: `feedback_no_commit_without_approval.md`.
- При явном поручении iOS build/archive/upload действовать по docs/IOS_UPLOAD.md без повторных вопросов о доступных локально credentials. Не печатать .env и не делать широкий поиск секретов. Отдельные build/upload выполняются только в порученном объёме; это не разрешение Submit/production. Источник: `feedback_ios_upload_autonomous.md`.
- IARC Global Rating ID сохранён в docs/CODEX_PROJECT_REFERENCE.md; при публикации сверить применимость текущему приложению, не переносить рейтинг автоматически на другой продукт. Источник: `reference_global_rating_id.md`.
- При порученном rip сначала проверить установленный apkeep; никакого brew install без согласования. Unity IL2CPP metadata даёт имена, а не тела методов; ассеты UnityPy читать как референс. Архив ../_rips не открывать одной лишь миграцией. Источник: `reference_apkeep_rip_pipeline.md`.

`MEMORY.md` перенесён как индекс; действующие уточнения выше, оригинальный текст не исполняется как Claude-инструкция.
